# 목화밭 감시자 (CottonViewer)

Discord 서버의 발언을 "진실", "거짓", "이게뭐노루" 중 하나로 판정하는 봇.

## 기능

### 주요 명령어

- **`/ㄱㅌ [텍스트]`** - 판정만 (확신도 마크다운 + 한줄평)
- **`/ㅅㅁ [텍스트]`** - 설명만 (판정 없이 한줄평만)

### 자동 감지

- **노루 경고**: "노루"(정타/우회/이모지/한자)를 감지하면 자동으로 친절한(?) 경고 메시지 발송
- **멘션 확인**: @멘션된 유저/역할/채널 이름에 "노루"가 포함되면 감지

## 구조

```
봇: 호스팅 서버(디스호스트 등)
  ↓
LLM: 로컬 PC (Ollama/exaone3.5:7.8b)
```

봇과 LLM은 별개 환경. 통신은 환경변수 `OLLAMA_BASE_URL`로 조정.

## 빠른 시작

### 1. 로컬에서 테스트 (개발용)

```bash
git clone <your-repo-url>
cd CottonViewer
npm install
cp .env.example .env
# .env에서 DISCORD_TOKEN과 OLLAMA_BASE_URL 입력
node index.js
```

### 2. 서버에 배포

전체 가이드는 [`DEPLOY.md`](DEPLOY.md) 참고.

**핵심 단계:**
1. 로컬 PC에서 Ollama 실행 + 터널링 (ngrok/Cloudflare)
2. 호스팅 서비스에 리포 클론
3. `.env` 작성 (DISCORD_TOKEN + OLLAMA_BASE_URL)
4. `npm install` → `node selftest.js` → 봇 시작

## 파일 가이드

| 파일 | 용도 |
|------|------|
| `index.js` | 봇 메인 로직 (명령어, 노루 감지, LLM 호출) |
| `selftest.js` | 배포 전 형식 검증 (네트워크 호출 없음) |
| `knowledge.md` | LLM에 주입되는 배경 지식 (서버별 설정) |
| `.env.example` | 환경변수 템플릿 |
| `DEPLOY.md` | 배포/설정 상세 가이드 |

## 모델

- **Ollama**: [exaone3.5:7.8b](https://ollama.ai/library/exaone)
- **호환성**: OpenAI SDK (`/v1` 엔드포인트)

## 판정 기준

| 판정 | 의미 | 예시 |
|------|------|------|
| **진실** | 명백한 사실 또는 타당한 진술 | "지구는 태양 주위를 돈다" |
| **거짓** | 앞뒤 안 맞는 핑계, 허풍 | "숙제 다 하고 게임할 거야" (하지 않음) |
| **이게뭐노루** | 의미 불명의 헛소리 또는 진위를 따질 수 없는 문장 | "ㅋㅋㅋㅋㅋ" |

### 확신도 (1~5)

- **5**: 빼박 사실/거짓 (`# 판정`)
- **4**: 정황 확실 (`## 판정`)
- **3**: 그럴듯하지만 반대 가능 (`### 판정`)
- **2**: 근거 부실 (`판정`)
- **1**: 거의 추측 (`-# 판정`)

## 보안

- `.env` 파일은 `.gitignore`에 등록 (절대 커밋하지 마라)
- `DISCORD_TOKEN` 노출 시 Discord Developer Portal에서 토큰 재발급
- 호스팅 서비스의 환경변수 관리 기능으로 민감 정보 보호
