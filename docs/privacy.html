개인정보처리방침

서비스명: 목화밭 감시자 (디스코드 봇) · 최종 수정일: 2026년 8월 7일

요약: 봇은 어떤 데이터도 저장하지 않는다.
데이터베이스, 로그 파일, 대화 기록이 존재하지 않는다. 각 요청은 처리 즉시 완결되고 메모리에서 사라진다. 외부로 나가는 것은 판정을 생성하기 위해 AI 제공자에게 보내는 대상 문장 하나뿐이다.

1. 봇이 수신하는 정보

봇은 디스코드로부터 자신이 참여한 채널의 메시지를 수신한다 (디스코드의 Message Content Intent 권한). 다만 /진실로 시작하지 않는 메시지는 수신 즉시 아무 처리 없이 폐기되며, 저장·전송·분석되지 않는다.

2. 실제로 처리되는 정보

사용자가 어떤 메시지에 답장한 뒤 /진실을 입력한 경우에 한해, 아래 정보가 처리된다.

답장 원본 메시지의 텍스트 판정 대상. AI 제공자에게 전송되는 유일한 내용이다.
채널 ID · 메시지 ID 원본 메시지를 불러오고 응답을 올바른 위치에 게시하기 위해 사용. 전송·저장하지 않는다.

이메일, 전화번호, 결제 정보, IP 주소는 수집하지 않는다. 사용자의 디스코드 비밀번호나 계정 정보에 접근하지 않는다.

3. 제3자 제공

판정 생성을 위해 위 대상 문장 텍스트를 미국 소재 Groq, Inc.의 API로 전송한다. 이것이 유일한 외부 전송이며, 국외 이전에 해당한다. Groq의 데이터 처리 방식은 Groq 개인정보처리방침을 참조하라.

그 외 어떤 제3자에게도 정보를 제공하거나 판매하지 않는다.

4. 저장 및 보관 기간

저장하지 않는다. 따라서 보관 기간도 없다. 봇은 상태를 유지하지 않으며(stateless), 이전 요청의 내용을 다음 요청에서 참조할 수 없다.

다만 오류 발생 시 진단 목적으로 봇 실행 서버의 콘솔에 오류 내용이 출력될 수 있다. 이는 프로세스 종료와 함께 사라지며 별도 파일로 영구 보관하지 않는다.

5. 이용자의 권리

봇이 저장하는 데이터가 없으므로 열람·정정·삭제할 대상이 존재하지 않는다. 봇의 메시지 수신 자체를 중단하고 싶다면 서버에서 봇을 추방하면 즉시 중단된다. 개별 판정 결과 메시지는 디스코드에서 직접 삭제할 수 있다.

6. 아동의 개인정보

봇은 디스코드 이용약관이 정한 최소 연령(만 13세 이상, 국가에 따라 상향) 이용자를 대상으로 한다.

7. 보안

봇의 인증 키는 운영자의 실행 환경에만 저장되며 코드 저장소에 포함되지 않는다. AI 제공자와의 통신은 HTTPS로 암호화된다.

8. 방침의 변경

본 방침은 이 페이지의 갱신으로 변경되며, 변경된 내용은 게시 시점부터 적용된다.
